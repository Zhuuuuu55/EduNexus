# MAIR · EduNexus 智联教枢

EduNexus 是面向计算机教育场景的智能教学平台，将课程知识、公共事务、算法学习、课件生成、模拟课堂与个人学习记录组织在同一个工作台中。

> 本仓库目前提供项目技术介绍。应用源码、课件、数据和可运行服务尚未在此仓库发布，因此目前无法从本仓库安装或在线使用完整系统。

## 平台功能

- **智能对话与课程知识**：结合课程范围和资料开展问答，支持将相关内容整理为学习笔记。
- **公共事务**：围绕学校提供的资料检索与回答，帮助用户查找相关信息。
- **算法学习**：结合题目、代码、运行与评测结果提供学习辅助；代码执行依赖独立的隔离环境。
- **PPT 生成**：围绕教学主题组织课件内容，使用 PPT Master 相关能力生成可编辑文件，并提供预览链路。
- **模拟课堂**：围绕课件进行学习，提供课堂标注、讲稿和个人笔记等功能。
- **学习笔记与产物**：将对话和课堂学习中的内容整理到个人学习空间，支持按笔记本管理。

## 技术架构

1. **交互层**：采用 React、TypeScript 和 Vite 构建工作台，组织对话、课堂和学习资料等界面。
2. **应用服务层**：采用 Node.js、TypeScript 和 Fastify，负责身份与权限、业务接口、任务状态以及个人学习数据。
3. **智能体运行层**：通过 Host、Harness 和领域能力组织任务。Host 连接具体业务场景；Harness 负责模型调用、工具与任务过程的组织；不同领域能力处理知识、事务、算法、课件等需求。项目包含 Pi Agent 集成与自研任务运行机制，具体启用范围取决于配置。
4. **知识检索**：知识问答与公共事务结合 RAG（检索增强生成），先从用户有权访问的资料中检索相关内容，再结合检索结果生成回答；项目包含 WeKnora 集成。
5. **课件制作**：集成 PPT Master 相关工具与处理流程，组织内容生成、检查与导出；预览和生成需要对应运行依赖及配置。
6. **数据与安全**：学习记录与任务状态由服务端管理；代码运行使用独立执行服务，并依赖实际部署中的容器隔离配置。

## 使用与部署说明

完整系统需要应用前后端，以及按功能配置的模型服务、知识库、课件生成与预览组件、代码执行隔离环境等。GitHub 上的技术介绍不会自动创建可用的在线系统；完整应用需另外部署。部分功能是否可用取决于对应服务和数据配置。
