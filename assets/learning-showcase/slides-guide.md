## 使用方式

- 固定 1920 × 1080 舞台，按浏览器窗口等比缩放，始终保持 16:9。
- 左右方向键、上下方向键、PageUp / PageDown、底部按钮翻页；空格进入下一页。Home / End 到首尾，数字键 1–9 跳页。
- G 打开目录，F 切换全屏。普通浏览器也可使用 F11；部分内置预览不支持网页全屏 API。
- 输入焦点在视频、选择器和页内标签时，保留各控件的键盘操作。标签支持左右键、Home / End。
- 页内媒体与右侧描述、下方特点同步切换。多张图片可以使用选择器或缩略图切换、点击放大。
- 翻页或切换演示时暂停视频，回看保留本次浏览中的播放位置与倍速。不会自动续播，不自动跳到下一页。
- 默认正常播放并保留原声。操作和等待过程可手动选择 1.25× / 1.5× / 2×；讲解、打断接续、步骤同步建议保留 1×。
- “完整录屏”可在单独页面播放，素材文件没有破坏性裁剪。对话保存的重复素材说明继续保留。
