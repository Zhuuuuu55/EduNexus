# 知识学习演示 · 本地预设版

## 打开方式

打开仓库根目录 `knowledge-showcase.html`，或访问本地预览服务的同名页面。无需 API Key，不会连接模型或向线上账号写入数据。HTML 仅使用同仓库中的品牌图标，正文、脚本与流程图均内嵌。

## 演示形式

两页：第一页面是一段连续对话，左侧四个时刻可以回看；第二页面讲解课程范围、连续追问、回答来源与显式保存。第一页面保留既往轮次，可滚动回看。

建议现场按“概念 → 追问 → 辨误 → 提纲”的顺序讲 2–3 分钟。点击“重播本轮”逐块展示回答，点击“显示完整回答”立即展开。自动演示以每轮回答展示后约 8.5 秒推进，可随时暂停。

最后一轮的自测答案默认折叠，由观看者自行展开。“保存本地提纲”使用当前浏览器的本地存储，“下载 Markdown”生成可继续编辑的文本文件，均不代表已写入项目服务端。

## 提问与现场讲解词

### 1. 概念理解

**提问**

结合数据结构课程中“栈与队列”的知识，说明两者有什么区别。请先讲规则，再用同一组元素举例，不要一开始就给代码。

**讲解**

先建立共同的学习对象，再用同一组数据比较不同规则。

### 2. 沿上下文追问

**提问**

那为什么函数调用通常用栈，打印任务通常用队列？沿用刚才的区别，分别给一个具体过程。

**讲解**

不用重述整段背景，接着上一轮的概念问真实用途。

### 3. 例题辨误

**提问**

按 1、2、3 的顺序入栈，期间允许穿插出栈。出栈次序 3、1、2 可能出现吗？请逐步解释，别只回答能或不能。

**讲解**

把规则用于判断一个具体序列，让学生看到结论从哪里来。

### 4. 整理与留存

**提问**

把刚才的讨论整理成一份简短复习提纲：规则、用途、易错点各一项，再给两道自测题，先不要展示答案。

**讲解**

从连续问答提炼结构化要点，用户明确决定是否留存。

## 技术说明的核对依据

以下为本地源码核对，不等同于当前线上部署结果：

- `apps/web/src/views/boardui-chat-starter-preview/useBoardMission.ts`：知识学习选定课程时携带当前课程范围。
- `apps/api/src/services/teaching-knowledge/active-context.ts`：识别对话延续与主题切换，维护当前课程知识背景。
- `apps/web/src/views/boardui-chat-starter-preview/PiMessages.tsx`：回答来源标注、后续提问、学习草稿与保存入口。
- `apps/api/src/services/agentic-runtime-next/action-plane/conversation-learning-drafts.ts`：从属于当前用户的已存回答保存学习内容，关联原会话、回答和引用。

## 真实平台录屏时怎么使用

1. 进入知识学习模式，选择数据结构课程，确认账号有相应课程资料权限。
2. 按上方四个提问顺序发送，不在中间新建会话。
3. 第一轮检查是否真正命中课程材料；有引用则打开核对，未命中时保留实际提示，不套用本页的示例标记。
4. 第三轮重点录下对“3、1、2 不可行”的逐步解释。
5. 最后按真实界面入口保存，再从个人产物或笔记中重新打开核对。
6. 若实际部署还未开放对应能力，仅演示已可用的问答部分；这里的本地保存不要当作线上保存成功。

## 本地实现与线上结果的区别

当前线上 IP 入口返回空响应，另一项目入口访问超时，因此本页使用预设对话，不是线上录屏、实时推理或真实检索结果。示例不标造课件页码，资料按钮明确说明标注为示意。

本演示为独立展示文件，不修改既有课堂与学习笔记展示；运行时使用预设内容，不连接线上模型。
